# career/

## Purpose

Work, personal brand, and own business sources.

## Put here

- Performance reviews, CVs, offer letters, role notes
- Consulting pipeline, client one-pagers, proposals (non-invoice)
- Brand content drafts, talk outlines, portfolio material
- AI / delivery career artifacts and certifications (copies or scans)

## Do not put here

- Signed employment contracts / legal PDFs if they are pure legal archive → [`../documents/`](../documents/) (or keep here if career-primary; do not duplicate)
- Salary slips and bank statements → [`../finance/`](../finance/)
- Meeting slots → [`../calendar/`](../calendar/)
- People CRM → [`../social/`](../social/)
- Personal diary → [`../manual/`](../manual/)

## Naming

- `YYYY-MM-DD-review-employer.md`, `cv-YYYY.pdf`, `offer-company-YYYY-MM.pdf`

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
