# social/

## Purpose

People and relationships: who matters, history, message context.

## Put here

- Person notes, relationship timelines
- Message/chat exports you choose to keep
- Social context that is about people, not about schedule or money

## Do not put here

- Meeting time slots → [`../calendar/`](../calendar/)
- Payments to/from someone → [`../finance/`](../finance/)
- Web articles → [`../internet/`](../internet/)
- Employer process docs → [`../career/`](../career/) or [`../documents/`](../documents/)

## Naming

- People: `person-firstname-lastname.md`
- Exports: `YYYY-MM-DD-chat-export.zip` (avoid secrets; strip tokens)

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
