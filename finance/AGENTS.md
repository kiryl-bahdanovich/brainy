# finance/

## Purpose

Money: income, expenses, accounts, tax and payment trails.

## Put here

- Bank/card exports, statements, budgets
- Invoices you send or receive, tax packs, investment exports
- Expense CSVs and accounting dumps

## Do not put here

- Event time of a paid meeting → [`../calendar/`](../calendar/)
- Who you paid / client relationship → [`../social/`](../social/)
- Offer letter narrative → [`../career/`](../career/)
- Generic PDFs unrelated to money → [`../documents/`](../documents/)

## Naming

- `YYYY-MM-bank-export.csv`, `invoice-2026-001.pdf`

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
