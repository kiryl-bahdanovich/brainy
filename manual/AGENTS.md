# manual/

## Purpose

Hand-written notes: thoughts, decisions, journals, self-authored prose.

## Put here

- Diary entries, decision logs, reflections
- Personal conclusions distilled from other sources
- Working notes that are yours, not clipped from the web

## Do not put here

- Raw web clips → [`../internet/`](../internet/)
- Binary documents → [`../documents/`](../documents/)
- Structured money/health/calendar exports → domain folders
- Career artifacts that are deliverables → [`../career/`](../career/)

## Naming

- `YYYY-MM-DD-topic.md` or clear slug; no spaces

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
