# documents/

## Purpose

Formal personal documents: books, contracts, scans, identity/legal papers.

## Put here

- Books, workbooks, PDFs you own as reference
- Employment/legal contracts, ID scans, visas, insurance policies
- Other durable personal documents without a clearer domain home

## Do not put here

- Bank statements / tax filings as money trail → [`../finance/`](../finance/)
- Lab results and clinical imaging → [`../health/`](../health/)
- World reports and public datasets → [`../statistics/`](../statistics/)
- Career drafts and brand writing → [`../career/`](../career/)
- Formatted pages synthesized from raw vault sources → [`../wiki/`](../wiki/)

## Naming

- No spaces; `Contract-Acme-2024.pdf`, `Passport-scan-YYYY.pdf`

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
