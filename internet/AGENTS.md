# internet/

## Purpose

Saved web material you did not write: articles, excerpts, clippings.

## Put here

- Clipped articles, HTML/MD saves, bookmarks dumps you want in-repo
- Excerpts with source URL in the file or filename

## Do not put here

- Your own synthesis or decision → [`../manual/`](../manual/)
- Your brand/career drafts → [`../career/`](../career/)
- Chat/message exports with people → [`../social/`](../social/)
- Public numeric datasets / big reports → [`../statistics/`](../statistics/)

## Naming

- `YYYY-MM-DD-source-slug.md` when possible; keep URL in frontmatter or body

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
