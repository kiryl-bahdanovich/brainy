# calendar/

## Purpose

Time and schedule sources for when things happen.

## Put here

- Calendar exports (ICS, CSV, Google/Outlook dumps)
- Event lists, time blocks, travel day plans tied to dates/times
- Recurring schedule snapshots

## Do not put here

- Who a person is or relationship history → [`../social/`](../social/)
- Money amounts / invoices → [`../finance/`](../finance/)
- Career narrative or offer letters → [`../career/`](../career/)
- Free-form reflection → [`../manual/`](../manual/)

## Naming

- Prefer dated exports: `YYYY-MM-DD-calendar-export.ics`
- One export per source/system when possible

## Shared rules

- Filenames: no spaces (skill `brain-fix` Step 2); prefer `YYYY-MM-DD-slug.ext`
- One canonical file per fact; other folders get a link or short pointer, not a duplicate
- This file is a hub **guide** (structure and purpose only) - not a file index
- Find notes via skill `brain-search` (hub + frontmatter); do not add `## Index` or file lists here
- Parent vault docs: [`../AGENTS.md`](../AGENTS.md), [`../ABOUT.md`](../ABOUT.md)
